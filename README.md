# HR Analytics Excel Project

## Project Overview
This project analyzes HR employee data using Microsoft Excel to identify workforce trends and patterns.

## Dataset
- Employee information
- Department-wise headcount
- Salary analysis
- Employee attrition
- Job satisfaction

## Tools Used
- Microsoft Excel
- PivotTables
- Excel formulas
- Charts and slicers

## Key Analysis
- Analyze employee count by department.
- Compare salaries across departments.
- Examine employee attrition.
- Identify patterns in job satisfaction.

## Outcome
The project demonstrates practical Excel data analysis and reporting skills.
